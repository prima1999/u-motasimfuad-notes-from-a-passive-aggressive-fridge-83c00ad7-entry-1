One funny passive-aggressive note a smart fridge leaves for its owner: a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen. It keeps count of a 2:14 a.m. door opening, calls the yogurt as a witness, and files the incident next to takeout from a restaurant that closed in 2019.

## Run it

```sh
node main.ts
```

The program writes the note to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Node standard library only, deterministic: every run writes the exact same bytes.
